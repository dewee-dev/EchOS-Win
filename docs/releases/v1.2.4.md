# EchOS-Win v1.2.4

**启动诊断与备份通道优化。** 针对 v1.2.3 使用中反馈的「授权不一致时启动慢、提示看不懂」与「部分网络环境下备份不可用」集中改进。

**修复**

- 修复：授权信息与服务端不一致时，启动长时间卡顿且无提示的问题。现在会在十几秒内明确告知原因并自动停止，任意场景只弹一次提示
- 修复：隧道启动失败时，部分情况下提示内容与真实原因不符的问题
- 修复：个别探针未通过时，托盘图标显示的状态与实际运行状态不一致的问题

**优化**

- 自检项目更名更直观：① 服务器地址可达 → ② 授权校验 → ③ 可访问 Google（经隧道），每一步在做什么一目了然
- 全局模式下自检不再包含「国内直连」一项——该模式下访问国内站点本就绕道海外，测了只会得到误导性的失败
- WebDAV 备份 / 还原优先直连，直连受阻时自动改经代理通道重试（代理通道含本应用隧道，无需手动切换系统代理设置）
- 授权失败的提示统一为两行式：原因一行、下一步一行
